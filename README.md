# 善治 Harness 插件集

面向 DeepSeek Harness 的业务插件集合，提供问数结果展示、问知文档与原文预览、查询规范与指标可信状态，以及公文处理能力。每个插件位于 `plugins/<插件名>`，独立安装、独立版本；仓库根目录不是可安装的插件包。

| --- | --- | --- | --- |

## 安装与升级

源码仓库：<https://github.com/shanzhi-digital/shanzhi-plugin>。

优先通过 DSH 的插件目录或官方插件管理器安装。安装后在“设置 → 插件”核对包名、版本、代码来源及组件状态；目录页显示“已安装”不等于组件已经正常运行。

本地开发安装时：

1. 克隆仓库到长期保留的位置。
2. 安装具体的插件子目录，例如 `plugins/datahub-echarts`，不要安装整个仓库根目录。目录链接安装依赖原目录持续存在，删除或移动工作树可能使插件失效。
3. 也可在插件目录执行 `npm pack --ignore-scripts` 生成独立 `.tgz` 包，再通过官方 CLI 安装到桌面 profile：

   ```powershell
   dsh plugin --profile desktop add "<插件安装包的绝对路径.tgz>"
   ```

4. 原始 GitHub 来源、打包文件来源和目录链接的升级方式不同，以插件管理器显示的来源为准。本地包不能自动获得远端新代码。
5. 安装后如宿主提示需要重启，或组件仍引用已失效的旧目录，应保存工作并完整退出桌面端后重开；普通页面刷新可能仍复用原 Host 进程。无需在每次正常生效的安装后重复重启。

GitHub 安装需要能够访问实际下载地址；仅能打开插件目录页面不代表源码包下载可用。公文插件还有 Python 运行依赖，详见其 README。数据源与知识库访问权限由对应 MCP 连接决定，本仓库不提供连接凭据。

## 业务能力与职责

### 问数结果展示

业务查询工具负责取数，图表插件复用当前会话当前回合已经成功返回的真实行列结果。普通问数默认显示表格，用户明确要求绘图时才默认显示图形；可以切换表格、柱状图、折线图和饼图。表头、数字与文字单元格统一水平居中。

同轮多份结果在一个结果区中通过标签切换，各自保留视图选择。CSV/XLSX 仅在用户点击导出并选择格式后生成，导出当前结果已加载的全部列；分页或截断结果只导出已加载部分，不自动补查。

展示需要模型调用 `query_result_chart` 或兼容入口 `datahub_chart`，插件不自动扫描正文 Markdown 表格，不监听所有查询结果，也没有内置多来源合并、JOIN 或差异计算功能。正文不重复完整表格属于模型输出指引，插件不会自动删除历史正文中的表格。来源工具、调用 ID 和 SQL 用于内部校验，不提供展开的来源界面。

### 问知文档与原文

问知 MCP 负责检索，文档插件区分“找文件”和“问知识”：前者展示“找到的文档”，后者展示“检索来源”及证据片段。模型通过 `knowledge_documents_present` 确认最终选择。原文入口基于真实检索返回的地址与有效期，点击后加载并交给右侧文件预览；不会凭文档名称猜测下载地址。

### 查询规范与指标可信状态

问数增强在首条 DataHub 语义 SQL 前引导读取公共规范，并要求中文业务结果使用准确中文别名。它提供提示，不拦截或代写 SQL。正文末尾按证据输出 1～3 条“数据洞察”；无足够证据或用户明确不要分析时省略。

可信标识依据本轮成功查询的 `usedMeasures` 自动汇总为“可信指标”“部分可信”或“数据由AI提取，注意辨别”。可信表示指标口径的人工确认状态，不保证查询结果或模型推测绝对正确。标识只在正常完成的业务查询回合显示，不为标识重复查询，独立子代理会话不自动并入。

查询摘要通过宿主附加上下文保存，刷新时重建，不复制业务数据行；仅有普通文字摘要的旧历史无法补造可信信息。搭配 `datahub_chart` 内部查询时，使用图表插件 0.10.1 或更新版本以转交可信摘要。

## 开发与目录

各插件的 `package.json` 是包名、版本、入口和分发文件的依据；目录结构按插件职责有所不同，不要求所有插件都包含 `core.js` 或 `results.js`。

客户端插件随包提供构建产物；图表插件的 ECharts、zrender 和 SheetJS 已内联，运行时无需另装这些前端依赖。源码及验证入口见各插件 README，图表构建说明见 [客户端构建与验证](plugins/datahub-echarts/build/README.md)。文档所述测试入口不表示所有宿主版本及干净环境已通过兼容验收。

发布时核对版本、介绍和分发文件，运行受影响测试；客户端有改动时重建产物并验证后发布。不要提交密钥、会话记录、业务查询数据或个人信息。
