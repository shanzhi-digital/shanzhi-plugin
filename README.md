# 善治 Harness 插件集

此仓库维护多个 DeepSeek Harness 插件，每个插件放在 `plugins/<插件名>` 目录下，独立版本、独立安装。

## 插件清单

| 目录 | 名称 | 版本 | 说明 |
|---|---|---|---|
| `plugins/datahub-echarts` | 通用查询结果图表 | 0.10.1 | 普通业务问数成功后由模型调用，默认表格；同轮结果集中于一个结果区，多表标签切换，支持视图切换、CSV/XLSX 数据导出与整体进一步分析，保留 DataHub 兼容入口 |
| `plugins/datahub-query-enhance` | 问数增强 | 0.1.1 | 提示模型在查询前读取公共技能、为展示列设置中文别名、在最终正文末尾输出数据洞察，并自动显示本轮指标可信状态 |

## 使用

1. 克隆本仓库到本机长期保留的位置。
2. 在 Harness 对话中让 Agent 通过插件管理器安装对应 `plugins/<插件名>` 目录（安装为目录链接，删除目录即失效）。
3. 首次安装或升级后刷新页面；桌面端如未生效请重启应用。
4. 每个插件的数据源访问权限由其使用的 MCP 连接决定，本仓库不含任何凭据，也不要在对话中提供密钥。

通用查询结果图表要求模型在普通业务问数获得最终成功的真实行列结果后调用 `query_result_chart`，默认显示表格；用户明确要求绘图时才默认显示图形。同轮查询结果集中在一个结果区，多表通过标签切换，单表不显示标签；每个结果各自保留视图选择。视图下拉支持表格、柱状图、折线图、饼图，复用已有结果，不重复查询；导出菜单提供 CSV 和 XLSX，导出当前选中结果已加载真实数据的全部列，图形视图同样导出数据。分页或截断结果只导出已加载部分，范围以结果备注为准。整轮最多显示一组三条“进一步分析”，位于结果区边框外；中间调用可省略 `followUps`，最后一次调用提供面向本轮全部结果的整体建议。插件展示成功后，模型正文只补充结论、口径与建议，不重复输出 Markdown 表格；这是模型输出指引，不表示插件会自动去除历史正文中的表格。结果区不显示插件版本脚注。来源工具、调用 ID 与 SQL 仅用于内部校验，不提供可展开来源界面。列数据源、读取表结构等元数据准备操作不触发结果区；用户明确只要文字时尊重其要求。展示由模型调用工具完成，插件不自动监听所有查询结果。

问数增强是独立插件，要求模型在本轮第一条 DataHub 语义 SQL 前成功调用 `mcp__datahub-ask-data__list_public_skills` 并读取相关规范；这是提示引导，不拦截 SQL。中文业务问数的最终展示列要求使用准确的中文别名，覆盖维度、聚合和计算列；单位须与实际值一致，执行前逐列检查。用户明确要求保留原字段名或使用其他语言时遵循用户要求。获得真实业务数据后，模型在最终正文末尾以“数据洞察”输出 1～3 条有依据的额外发现，区分事实与推测；证据不足或用户明确不要分析时省略。已有表格、图表和跟问仍由结果插件承载。

可信标识自动读取当前会话当前回合的成功 DataHub 查询，按 `usedMeasures` 汇总：全部可信且没有缺失度量信息时显示“可信指标”；可信与不可信或缺失信息并存时显示“部分可信”；没有可信度量时显示“数据由AI提取，注意辨别”。前两者的 `?` 点击展开说明。`usedMeasures: []` 计入缺失度量信息；同一指标不同 `trustHash` 分开计算。标识位于本轮结果区之后、操作按钮之前，仅正常完成后显示；失败、取消、中断或无业务查询时隐藏。可信表示指标口径确认状态，不保证模型洞察中的推测。独立子代理会话不自动并入主会话。

插件通过宿主附加上下文保存精简可信摘要，不复制业务数据行，刷新时从已保存事件重建。仅保留表格或文字摘要的旧历史无法补造可信信息；完整原始查询 JSON 可用于历史解析。搭配 `datahub_chart` 内部查询时使用本仓库图表插件 0.10.1 或更新版本，以转交可信摘要。

## 目录约定

- 每个插件包含：运行文件（`index.js`、`core.js`、`results.js`、`client.js`、`cordis.patch.yml`、locale、icon）、第三方许可文件，以及 `build/` 下的客户端构建源与烟测脚本。
- 新增插件请沿用同一结构，并在本文件的清单中登记名称、版本与说明。
