# 善治 Harness 插件集

此仓库维护多个 DeepSeek Harness 插件，每个插件放在 `plugins/<插件名>` 目录下，独立版本、独立安装。

## 插件清单

| 目录 | 名称 | 版本 | 说明 |
|---|---|---|---|
| `plugins/datahub-echarts` | 通用查询结果图表 | 0.7.0 | 消费当前会话真实查询结果，提供图表/表格切换和三个跟问，保留 DataHub 兼容入口 |
| [plugins/dsh-datasource](plugins/dsh-datasource/README.md) | 数据源 | 0.7.0-local.2 | 本地定制 dsh-sql：连接管理、问题驱动后台分析、表与关系分别确认，跟随官方主题；保留三个只读 SQL 工具及受绑定会话限定的结构化回填工具 |

## 使用

1. 克隆本仓库到本机长期保留的位置。
2. 在 Harness 对话中让 Agent 通过插件管理器安装对应 `plugins/<插件名>` 目录（安装为目录链接，删除目录即失效）。
3. 首次安装或升级后刷新页面；桌面端如未生效请重启应用。
4. 图表插件使用已经授权的 MCP 查询结果；数据源插件在自己的页面配置直连数据库，凭据通过 DSH 原生凭据服务保存。本仓库不含凭据，不要在对话中提供密钥。

## 目录约定

- 每个插件包含独立包配置、Host 入口、客户端入口、安装补丁、使用说明和适用的许可证。图表插件包含构建源与烟测脚本；数据源插件直接维护可执行客户端代码及后端/Host 测试，无额外打包器。
- 新增插件请使用独立目录，并在本文件的清单中登记名称、版本与说明。

## 维护

- 发布插件新版本时：修改 `package.json` 的 `version` → 跑测试 → 重建客户端产物 → 烟测 → 提交并打版本标签。
- 不要在仓库中保存密钥、会话记录、业务查询数据或个人信息。
