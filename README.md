# 善治 Harness 插件集

此仓库维护多个 DeepSeek Harness 插件，每个插件放在 `plugins/<插件名>` 目录下，独立版本、独立安装。

## 插件清单

| 目录 | 名称 | 版本 | 说明 |
|---|---|---|---|
| `plugins/datahub-echarts` | 通用查询结果图表 | 0.10.0 | 普通业务问数成功后由模型调用，默认表格；同轮结果集中于一个结果区，多表标签切换，支持视图切换、CSV/XLSX 数据导出与整体进一步分析，保留 DataHub 兼容入口 |

## 使用

1. 克隆本仓库到本机长期保留的位置。
2. 在 Harness 对话中让 Agent 通过插件管理器安装对应 `plugins/<插件名>` 目录（安装为目录链接，删除目录即失效）。
3. 首次安装或升级后刷新页面；桌面端如未生效请重启应用。
4. 每个插件的数据源访问权限由其使用的 MCP 连接决定，本仓库不含任何凭据，也不要在对话中提供密钥。

通用查询结果图表要求模型在普通业务问数获得最终成功的真实行列结果后调用 `query_result_chart`，默认显示表格；用户明确要求绘图时才默认显示图形。同轮查询结果集中在一个结果区，多表通过标签切换，单表不显示标签；每个结果各自保留视图选择。视图下拉支持表格、柱状图、折线图、饼图，复用已有结果，不重复查询；导出菜单提供 CSV 和 XLSX，导出当前选中结果已加载真实数据的全部列，图形视图同样导出数据。分页或截断结果只导出已加载部分，范围以结果备注为准。整轮最多显示一组三条“进一步分析”，位于结果区边框外；中间调用可省略 `followUps`，最后一次调用提供面向本轮全部结果的整体建议。插件展示成功后，模型正文只补充结论、口径与建议，不重复输出 Markdown 表格；这是模型输出指引，不表示插件会自动去除历史正文中的表格。结果区不显示插件版本脚注。来源工具、调用 ID 与 SQL 仅用于内部校验，不提供可展开来源界面。列数据源、读取表结构等元数据准备操作不触发结果区；用户明确只要文字时尊重其要求。展示由模型调用工具完成，插件不自动监听所有查询结果。

## 目录约定

- 每个插件包含：运行文件（`index.js`、`core.js`、`results.js`、`client.js`、`cordis.patch.yml`、locale、icon）、第三方许可文件，以及 `build/` 下的客户端构建源与烟测脚本。
- 新增插件请沿用同一结构，并在本文件的清单中登记名称、版本与说明。

## 维护

- 发布插件新版本时：修改 `package.json` 的 `version` → 跑测试 → 重建客户端产物 → 烟测 → 提交并打版本标签。
