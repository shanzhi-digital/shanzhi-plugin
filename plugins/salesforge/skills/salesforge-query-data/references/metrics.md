# 销售管理数据口径

## 单位

项目预计金额、销售目标、看板金额全部是**万元**。回答时写清单位，不要换算成元。

## 项目阶段和风险

- 阶段（`projectStatus`，共 9 个，按推进顺序）：发现问题 → 技术预研 → 方案论证 → 立项审批 → 启动采购 → 制定标准 → 商务招标 → 项目签约；另有「项目丢单」。
- 前 7 个是在跟的商机；「项目签约」「项目丢单」是已结束的，项目列表和金额汇总**默认不包含**，要看时设 `includeArchived=true` 或直接指定阶段。
- 风险（`projectRisk`，共 3 个）：必签项目、时间风险、赢单风险。没标风险的项目这一列为空。这是销售自己在系统里标的，系统不会自动判断。按字面理解：
  - 必签项目：这一期要确保签下的项目，通常是完成目标的主要依靠。
  - 时间风险：可能不能按预计签约日期签下。
  - 赢单风险：可能丢单。
  具体含义以公司的规定为准，用户有不同说法时按用户的。

## 距上次跟进天数

- 客户、渠道：从最近一条日报（拜访或跟进记录）到今天的天数。
- 项目：从最近一次项目梳理到今天的天数。
- 都没有记录时，从新增那天算起。

## 季度

`quarter` 只表示**今年**的第几季度（按预计签约日期）。问去年的季度，用 `expectedSignFrom`、`expectedSignTo` 指定日期区间。

## 目标和完成

- 已完成金额：预计签约日期落在统计周期内、阶段为「项目签约」的项目金额合计。
- 本季度目标：系统里设置的季度目标。
- **本月目标：系统里没有，插件按年度目标除以 12 估算**。引用时必须说明是估算。
- 首页看板（`view="home"`）里的「年度目标」是年度目标，「本月签约占年度目标（%）」是本月签约额占年度目标的比例，不是本月完成率。

## 商机储备看板

`view="opportunity"` 统计预计签约日期在统计周期开始之后的商机，**包含已签约和已丢单的项目**，所以和项目金额汇总（默认不含这两类）的数字对不上是正常的，回答时说明口径。

## 市场拓展看板

`view="market"` 按项目新增时间落在统计周期内统计新增项目数和金额。

## 数据范围

- 售前岗位：能看本部门及下级部门的全部客户、渠道、项目和日报。
- 销售岗位：能看自己负责的数据，加上下级部门的数据。
- 看不到的数据，工具查不到，也不能绕过。
