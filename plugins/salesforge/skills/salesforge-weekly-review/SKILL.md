# 周报复盘

把一周的拜访、计划和周报拼起来，写成一份能直接修改使用的复盘草稿。

## 什么时候用

- 用户要写周报、做周复盘，或想看某个下属这周做了什么。
- 只想看日报列表：用「查数据」skill（`salesforge-query-data`）。

## 开始前

- 需要已连接销售管理系统账户。任何工具返回 kind 为 `salesforge-auth-required` 时：把 message 原样转告用户，停下等用户回复「继续」，不要重试或绕过。
- 弄清**哪一周**：默认本周。用户说「上周」「11 月第三周」时换算成那周的周一到周日。
- 弄清**看谁**：
  - 默认自己。先调用 `sales_config`（`action="profile"`）拿到自己的 `userId` 和姓名。**日报和周报不填汇报人时会返回你能看到的所有人的**，所以查自己时必须把 `userId` 作为 `reporterId` 传入。
  - 看下属：`reporterName` 填姓名；返回 `salesforge-person-unresolved` 时请用户从候选里选，再用 `reporterId`。

## 只读，不生成、不提交

- 销售管理系统里的「生成周报」会写入数据，插件没有这个工具，你也**不要**尝试用别的办法调用。
- 产出只是给用户看的草稿。用户要提交，请他复制到销售管理系统网页里填写。

## 步骤

### 1. 取这一周的数据

| 要什么 | 调用 |
|---|---|
| 拜访和跟进记录 | `sales_query_work_reports`：`mode="daily"`，`startDate` 填周一，`endDate` 填周日，`reporterId`，`pageSize=50`。`hasMore` 为 true 时用 `pageNum` 继续取完 |
| 这周的周计划 | `sales_query_work_reports`：`mode="weekly_plan"`，`weekStartDate` 填这周任意一天；看下属时加 `reporterId` |
| 已经写过的周报 | `sales_query_work_reports`：`mode="weekly_reports"`，`weekStartDate`，`reporterId` |
| 这周新增的项目（可选） | `sales_query_projects`：`mode="list"`，`createdFrom` 周一，`createdTo` 周日，`salesId` 填同一个人 |

周计划返回 `note`「这一周还没有填写周计划」时，复盘里就不做计划对照，直接说明没有周计划。

### 2. 整理

1. **拜访概况**：拜访了几次，覆盖几家客户、几家渠道；按对象归并，同一客户多次拜访合成一行。
2. **计划对照**：周计划的每一条，到日报里找对应记录（按客户名、渠道名、关键词对）：
   - 找到了：标「已完成」，写上对应日报的日期；
   - 部分对上：标「部分完成」，说明差在哪；
   - 找不到：标「日报里没有看到对应记录」。**不要写成「没做」**，可能只是没写日报。
3. **计划外工作**：日报里有、周计划里没有的拜访。
4. **问题和风险**：从日报「工作总结」里提炼客户提到的顾虑、卡点、需要支持的事。只提炼原文里有的，不要加。
5. **下周重点**：
   - 本周计划里没完成的；
   - 日报里约定了下一步的（例如「下周再沟通报价」）；
   - 可选：这个人负责的、预计签约日期在未来 30 天内的项目（`sales_query_projects`，`mode="list"`，`expectedSignFrom` 今天，`expectedSignTo` 30 天后，`salesId`），提醒推进。

### 3. 写草稿

按 `templates/weekly-review.md` 的结构写，要求：

- 用第一人称（看自己时）或第三人称（看下属时）。
- 每一条都能在日报、周计划、周报里找到出处；没有数据的部分写「本周没有相关记录」，不要编。
- 已经写过周报时，在开头说明「系统里已有这周的周报」，并把草稿当作补充或对照，不要覆盖用户的原意。
- 草稿末尾写一句：「以上是根据系统记录生成的草稿，请核对后自行提交。」

## 常见问题

| 现象 | 处理 |
|---|---|
| 这一周一条日报都没有 | 说明系统里这周没有拜访记录，问用户是否看错了周，或者只根据周计划写一个简短的待补充版本 |
| 日报很多（超过 100 条，常见于看整个团队） | 先按汇报人统计条数，再问用户要看谁的详细复盘 |
| 用户要看整个团队的周报 | 不填汇报人调用 `mode="weekly_reports"` 和 `mode="daily"`，按人汇总成一张表：姓名、拜访次数、覆盖客户数、周报是否已写 |
