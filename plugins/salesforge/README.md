# 销售管理

在小智办公里直接问销售数据：客户和渠道、项目商机、销售看板、日报周报、销售目标；也可以让它帮你写日报、录客户、改项目，在对话里把销售管理系统的日常操作做完。

插件以你在销售管理系统（SalesForge）里的账号身份工作，能看什么、能改什么和你在网页上一样：售前看本部门及下级部门的数据，销售看自己负责的数据加下级部门的数据。**删除和移交负责人要你在对话里的卡片上点确认才会执行**；用户、角色、部门、系统配置和产品列表不能通过插件修改。

## 连接账户

第一次使用前，需要把小智办公连接到你的销售管理系统账号。整个过程在浏览器里完成，不需要在小智办公里输入账号密码。

1. 在插件页点「管理」，再点「连接账户」。也可以在「设置 → 销售管理配置」里操作。
2. 小智办公会弹出一个窗口，显示一串**校验码**，同时在浏览器里打开销售管理系统的授权页。浏览器没有自动打开时，点窗口里的「没有自动打开？点这里打开授权页」。
3. 在授权页登录销售管理系统（已登录就跳过），核对页面上的校验码和小智办公里显示的一致，选好有效期，点「授权」。
4. 回到小智办公，窗口会显示「已连接：张三（zhangsan）」，就可以开始用了。

校验码 10 分钟内有效。只有在你刚刚点了「连接账户」时才在授权页点「授权」；看到不认识的授权请求，点「拒绝」。

## 试用

插件页右上角的「试用」会打开一个新会话，并在输入框里填好一句示例问题（不会自动发送），你可以改完再发。还没有连接账户时，会先带你完成授权，再打开会话。

插件页说明下方的「试试这样问」里有几个完整的问法，点一下会打开新会话并填好这句话，按回车发送：

- 看看我本季度的销售目标完成了多少、还差多少，再列出预计本季度签约但还没签下来的项目，按金额从大到小排，有时间风险或赢单风险的单独标出来
- 找出我负责的、超过 30 天没跟进的客户和渠道，按未跟进天数从多到少排成一张表，挑最久的五家看看上次拜访都聊了什么
- 汇总我这周的日报和下周的周计划：这周拜访了哪些客户和渠道、各谈到了哪一步，下周打算跟进谁，整理成几条要点给我

也可以直接在对话里提问，比如「张三这个月拜访了哪些客户」「李四还在商务招标阶段的项目有哪些」。

## 写日报

直接说拜访了谁、谈了什么、下一步打算，比如「今天拜访了华光科技的刘老师，演示了数据平台，客户认可方案，下周提交报价，帮我记个日报」。

1. 插件会在对话里显示一张「工作日报草稿」卡片：拜访日期、拜访对象、拜访人、工作总结、工作计划。
2. 核对内容，需要的话直接在卡片上改。拜访人从这个客户或渠道的联系人里选；客户还没有联系人时，要先在销售管理系统网页里添加。
3. 点「提交日报」，日报以你的名义写入销售管理系统，卡片显示「已提交 · 日报 #编号」。

不点「提交日报」就不会写入。工作总结和工作计划照你说的原话写，只改正错别字和标点，不会替你扩写或补内容。小智办公重启后，还没提交的草稿会失效，让助手重新生成一份即可。

## 修改和删除

直接说要改什么，比如：

- 「把华光科技的行业改成教育，再加个联系人王主任，电话 138…」
- 「数据平台那个项目推进到商务招标了，预计金额改成 120 万」
- 「昨天那条日报的拜访人写错了，应该是陈工」
- 「给李四定一下明年的目标，每个季度 50 万」

新建和修改会直接以你的名义写入，助手会告诉你改了哪些字段。

**删除和移交负责人要你确认。**比如说「删掉 596 号日报」「把这三个客户移交给张三」，对话里会出现一张「确认删除」或「确认移交」卡片，列出每一条要处理的数据：

1. 核对列表，没问题就点「确认删除」或「确认移交」；不想做了点「取消」。
2. 卡片会显示每一条的结果。删除后不能在系统里恢复。

不点确认就不会执行。小智办公重启后，还没确认的卡片会失效，让助手重新发起即可。

## 管理账户

插件页的「管理」（或「设置 → 销售管理配置」）列出所有已连接的账户：

- **当前使用**：对话里的查询都用这个账户。可以连接多个账户，在账户右侧的「⋯」菜单里点「设为当前」切换。
- **已过期 / 已失效**：授权到期，或者在销售管理系统里被吊销了。点「重新授权」，按上面的步骤再授权一次即可。
- **断开连接**：在「⋯」菜单里点「断开连接」并确认。插件会通知销售管理系统吊销这台设备的授权，并删除本机保存的令牌。
- **连接另一个账户**：再走一遍授权流程。在授权页登录哪个账号，就连接哪个账号；同一个账号再次授权会替换旧的授权。

插件页标题旁会显示连接状态：「已连接 · 张三」「授权已失效」或「未连接」。

对话中如果出现「还没有连接销售管理系统账户」「销售管理系统授权已过期」或「销售管理系统授权已失效」的卡片，点卡片上的「连接账户」完成授权，然后回复「继续」，刚才的问题会接着处理。

在销售管理系统网页里，也可以进入「插件授权」，查看并吊销用你的账号授权过的设备。

## 服务器设置

在「管理」窗口展开「服务器设置」：

- **服务器地址**：销售管理系统的接口地址，以 `/api/v1` 结尾，默认是 `http://132.232.203.59:7001/api/v1`。已连接账户时更换地址，会先提示确认，保存后断开全部账户，需要在新服务器上重新连接。
- **测试连接**：测的是输入框里的地址，不用先保存。地址改了还没保存时，检查它能不能连上、是不是支持插件授权的销售管理系统；地址没变时，再用当前账户访问一次，确认授权正常。

需要销售管理系统先升级到支持插件授权的版本（由系统管理员完成）。还没升级时，连接账户会提示「销售管理系统还没升级到支持插件授权的版本，请联系管理员」。

## 令牌存在哪里

授权后，销售管理系统签发的访问令牌只保存在这台电脑上，界面上任何地方都不会显示它：

- 一般情况下保存在小智办公的凭据存储中（`~/.dsh/.credentials.yaml`，仅本人可读）；
- 如果当前环境没有凭据存储，保存在 `~/.salesforge/credentials.json`（仅本人可读）。

「管理」窗口底部会说明当前用的是哪一种。`~/.salesforge/dsh-config.json` 只保存服务器地址和账户的姓名、部门等公开信息。插件令牌只能读写客户、渠道、项目、工作报告和销售目标，不能管理用户、角色和系统配置，也不能用来在网页上登录。不再使用的设备请在销售管理系统网页的「插件授权」里吊销。

## 常见问题

**浏览器没有打开授权页？** 点授权窗口里的「没有自动打开？点这里打开授权页」。

**提示「授权请求已过期」？** 10 分钟内没有完成授权，点「重试」会生成新的校验码。

**提示「你在销售管理系统里拒绝了这次授权」？** 如果是误点，点「重试」重新授权。

**对话里提示授权已失效？** 授权到期或在销售管理系统里被吊销了，点卡片上的「连接账户」重新授权，再回复「继续」。

**查不到已签约的项目？** 项目列表默认不含「项目签约」「项目丢单」的项目，问的时候说清楚「包括已签约的」即可。

**金额是什么单位？** 和销售管理系统网页一致，项目金额、目标和看板金额都是「万元」。

**点「提交日报」提示「拒绝了这次提交」？** 账号没有新建日报的权限，或者销售管理系统还没升级到允许插件提交日报的版本，请联系管理员。

**修改或删除时提示「拒绝了这次操作」？** 账号没有这项权限，或者销售管理系统还没升级到允许插件修改数据的版本，请联系管理员。提示「没有权限做这项操作」时，说明这条数据不归你管（例如别人写的日报），和网页上的规则一样。

## 工具清单

| 工具 | 用途 | 调用的接口（前缀 `/api/v1`） |
| --- | --- | --- |
| `sales_config` | 查看连接状态；`action="profile"` 查看当前账户的部门、角色、岗位和权限 | 本地配置；`GET /auth/info` |
| `sales_search` | 按名称搜客户和渠道；列出你能查看的人员 | `GET /search/all`、`GET /users/scope` |
| `sales_query_customers` | 客户列表，可按名称、行业、负责销售、新增时间、未跟进天数筛选 | `GET /customers` |
| `sales_query_channels` | 渠道列表，可按名称、负责销售、新增时间、未跟进天数筛选 | `GET /channels` |
| `sales_query_projects` | 项目商机列表和金额汇总，可按阶段、风险、季度、金额、负责销售、客户、渠道、预计签约日期筛选和排序 | `GET /projects`、`GET /projects/summary` |
| `sales_dashboard` | 首页概览、销售完成（目标、已完成、还差多少）、商机储备、市场拓展 | `GET /projects/dashboard/home`、`/sales`、`/opportunity`、`/market` |
| `sales_query_work_reports` | 日报（拜访和跟进记录）、周报、周计划 | `GET /work-reports`、`/work-reports/weekly-reports/list`、`/work-reports/weekly-plans` |
| `sales_targets` | 个人年度和季度目标；各部门目标与完成率 | `GET /sales-targets/personal-completion`、`/team-completion` |
| `sales_get_record` | 一个客户、渠道、项目或一条日报的详情：联系人、部门、梳理记录、项目分析（不含联系人电话） | `GET /customers/{id}`、`/channels/{id}` 及其 `/contacts`、`/depts`；`GET /projects/{id}` 及其 `/reviews`、`/analysis`；`GET /work-reports/{id}` |
| `sales_draft_work_report` | 生成工作日报草稿卡片；你点「提交日报」后才新建日报 | `GET /customers/{id}`、`/channels/{id}` 及其 `/contacts`；提交时 `POST /work-reports` |
| `sales_save_customer` | 新建、修改客户和渠道，添加、修改联系人，添加部门 | `POST /customers`、`PUT /customers/{id}`、`POST /customers/{id}/contacts`、`PUT /customers/contacts/{id}`、`POST /customers/{id}/depts`（渠道同理） |
| `sales_save_project` | 新建、修改项目，添加、修改项目梳理记录，保存项目分析 | `POST /projects`、`PUT /projects/{id}`、`POST /projects/{id}/reviews`、`PUT /projects/reviews/{id}`、`PUT /projects/{id}/analysis` |
| `sales_save_work_report` | 修改日报，保存周计划和周报 | `PUT /work-reports/{id}`、`PUT /work-reports/weekly-plans`、`PUT /work-reports/weekly-reports` |
| `sales_save_target` | 设置个人或部门的年度、季度目标 | `GET /sales-targets`、`POST /sales-targets` |
| `sales_delete` | 显示「确认删除」卡片；你点确认后才删除 | 确认时 `DELETE` 对应的数据 |
| `sales_transfer` | 显示「确认移交」卡片；你点确认后才把客户、渠道或项目移交给别人 | 确认时 `POST /customers/transfer`、`/channels/transfer`、`/projects/transfer` |

按人员查询（例如「张三的客户」）时，插件会先确认这个人在你的可见范围内，再去查询。列表和看板数据可以配合「问数表格与图表」插件（`@local/datahub-echarts`）展示为交互表格和图表。

## 内置 skill

插件自带 6 个 skill，把常见的销售管理工作写成了固定步骤。装好插件后：

- 在输入框打 `/`，就能看到并选择这些 skill；
- 不点名也可以，直接说需求（例如「分析一下我的项目」），模型会按 skill 的说明自动加载。

| skill | 做什么 |
|---|---|
| `salesforge-query-data` 查数据 | 把问题拆成查询，人名、客户名先换成 ID，处理分页，用表格给出结果并注明来源和筛选条件；查不到就说查不到 |
| `salesforge-project-analysis` 项目分析 | 按阶段、金额、风险、预计签约时间分析商机，找出签约日已过、久未梳理、风险金额大的项目，给出结论和建议 |
| `salesforge-target-tracking` 目标完成追踪 | 看个人和团队的完成率、缺口，和时间进度对比，判断必签项目和近期商机能不能补上缺口 |
| `salesforge-customer-followup` 客户跟进提醒 | 找出超过 N 天（默认 30 天）没跟进的客户和渠道，结合最近拜访和在跟项目排出跟进计划 |
| `salesforge-weekly-review` 周报复盘 | 汇总一周的拜访、周计划和周报，写成复盘草稿；你确认后保存成周报 |
| `salesforge-edit-data` 维护数据 | 新建、修改客户、渠道、联系人、项目、日报、周报和目标：先找准是哪一条，只改你要求改的字段；删除和移交先出确认卡片 |

几点说明：

- 客户跟进提醒里，跟进完要记日报时会生成日报草稿，由你在卡片上提交；周报复盘先出草稿，你说保存才写入，不会调用系统的「生成周报」。
- 「本月目标」系统里没有，插件按年度目标除以 12 估算，skill 引用时会注明。
- skill 跟着插件一起启用和停用，不需要单独设置。
