# 问数增强（datahub-query-enhance）

DeepSeek Harness 的 DataHub 查询辅助插件，包名 `@local/datahub-query-enhance`，版本 **0.1.1**。负责查询规范提示、中文结果列名、数据洞察及指标可信状态；表格、图表和导出由独立的 [通用查询结果图表插件](../datahub-echarts/README.md) 提供。

## 功能与边界

### 查询规范与中文列名

在本轮第一条 DataHub 语义 SQL 前，引导模型成功调用 `mcp__datahub-ask-data__list_public_skills` 并读取相关规范，再按需获取数据源和模型定义。同一回合后续分页、修正和补查可复用已读取的规范。

中文业务查询的最终展示列使用准确的中文别名，覆盖维度、聚合和计算列，单位与真实返回值一致。用户明确要求保留原字段名或使用其他语言时遵循用户要求。

以上通过系统提示引导模型执行，不是强制 SQL 拦截器，也不保证模型每次都遵循。不提供 SQL 执行器，不新增 Python、PowerShell、跨表合并或子代理处理流程。

### 数据洞察

模型先完成用户问题的直接回答，再在正文末尾用“数据洞察”输出 1～3 条有依据的额外发现，区分事实与推测。分页结果不当作全量分布，没有时间对比不声称增长；证据不足，或用户要求仅数据、不要分析、简短回答时省略。

已有结果继续复用，不为洞察或可信标识重复查询，也不重复图表插件的“进一步分析”问题。

### 指标可信状态

插件自动读取当前会话当前回合成功的 DataHub 语义查询元数据，按 `usedMeasures` 汇总，在正常完成的业务回合显示：

| 状态 | 含义 |
| --- | --- |
| 可信指标 | 所有度量均可信，且没有缺失度量信息 |
| 部分可信 | 可信度量与不可信或缺失度量信息并存 |
| 数据由AI提取，注意辨别 | 没有可信度量 |

前两种状态可点击 `?` 查看说明。`usedMeasures: []` 视为缺失度量信息；同一指标的不同 `trustHash` 分开计算。可信表示指标口径的人工确认状态，不表示模型推测得到人工确认，也不保证所有数据或分析绝对正确。

标识位于本轮结果区域之后、操作按钮之前；失败、取消、中断或没有业务查询的回合不显示。它不需要模型额外调用展示工具，独立子代理会话不自动汇入主会话。

宿主附加上下文保存精简可信摘要，不复制业务数据行，刷新时从事件重建。仅有普通文字或表格摘要的旧历史无法补造缺失的可信元数据。使用 `datahub_chart` 的内部查询时，搭配本仓库图表插件 **0.10.1 或更新版本**，以转交附加上下文。

## 安装

需要已授权的 DataHub 问数 MCP；仅安装此插件不会获得数据源访问权限。本版本的 DSH peer API 声明为 `0.2.2-rc.1`，其他宿主版本的兼容性需实际验证。

通过插件目录或官方插件管理器安装 `plugins/datahub-query-enhance`，不要安装整个仓库根目录。目录链接安装需保留源码目录；也可在本目录执行 `npm pack --ignore-scripts`，再用 `dsh plugin --profile desktop add "<安装包绝对路径.tgz>"` 安装独立包。

安装后核对包名、版本、来源和运行状态。宿主要求重启或仍引用旧目录时，完整退出桌面端后重开。通用说明见 [仓库 README](../../README.md)。

## 开发与验证

- `index.js`：查询规范、列名及数据洞察提示。
- `trust.js`：查询元数据归一化与可信状态计算。
- `host-bridge.js`：可信摘要的宿主上下文桥接。
- `event-projection.js`：事件回放、回合完成状态与显示范围。
- `build/client-entry.js`、`client.js`：可信标识的客户端源码与构建产物。

在插件目录运行：

```powershell
node --test trust.test.js host-bridge.test.js event-projection.test.js
```

客户端构建入口为 `build/rebuild.mjs`，浏览器验证入口为 `build/browser-smoke.mjs`，参数见脚本开头。提示遵循情况与真实查询元数据仍需在目标 DSH 中验收，不能用静态测试替代。
