# 版本记录

## 0.10.0

- 同轮查询结果集中在一个结果区，多表通过标签切换，单表不显示标签；每个结果各自保留视图选择，CSV/XLSX 导出当前选中结果已加载真实数据的全部列。
- 插件展示成功后，模型正文只补充结论、口径与建议，不重复输出 Markdown 表格；这是模型输出指引，不表示插件会自动去除历史正文中的表格。
- 整轮最多显示一组三条“进一步分析”，位于结果区边框外；中间调用可省略 `followUps`，最后一次调用提供面向本轮全部结果的整体建议。
- 移除结果区的插件版本脚注；来源工具、调用 ID 与 SQL 继续用于内部校验，保留真实数据导出及分页、截断范围说明。

## 0.9.0

- 将表格、柱状图、折线图、饼图切换收为视图下拉；三个跟问移至卡片边框外。
- 新增 CSV/XLSX 导出菜单，导出已加载真实数据的全部列；图形视图同样导出数据，不导出图片。分页或截断时通过备注说明只导出已加载范围，不自动读取其他页。
- CSV 使用 UTF-8 BOM，并保护可能触发公式的前缀文字；XLSX 保留原始文本和数值类型，设置表头与列宽。
- 移除可展开查询来源界面，来源工具、调用 ID 和 SQL 仍用于内部校验。
- 构建时内联官方 SheetJS CE 0.20.3，`rebuild.mjs` 增加第三个 `xlsxDir` 参数；运行时无需用户安装，随包加入 `LICENSE-SHEETJS`。
- 新增 `build/export.test.js`，通过 `XLSX_DIR` 和 `ESBUILD_DIR` 运行导出回归；浏览器烟测增加 `--xlsx-dir` 参数，用于读回下载文件验证内容。

## 0.8.0

- 普通业务问数取得最终成功的真实行列结果后，要求模型调用 `query_result_chart`，默认显示表格；用户明确要求绘图时才默认显示图形，保留表格、柱状图、折线图、饼图四种视图切换。
- 明确由模型根据工具说明调用展示工具，插件不自动监听所有查询结果；列数据源、读表结构等元数据准备操作不触发展示。
- 复用当前会话已有结果，不为展示重复查询；用户明确只要文字时尊重其要求，不调用展示工具。

## 0.7.0 — 2026-11-03

- 新增 `query_result_chart`：绑定当前回合已完成查询的真实 JSON 结果，支持对象数组、列定义加对象行或二维行、显式 JSON Pointer 嵌套路径。
- 唯一来源自动绑定；多个来源返回可选调用 ID。兼容模型可见的 OpenAI 调用 ID 与 Harness 组合调用 ID。
- 不执行新 SQL、不接受模型自填 rows；保留 SQL 来源信息。DataHub 语义来源仍检查 SQL 与数据源一致性，原 `datahub_chart` 保持兼容。
- 两个入口共用卡片，保留柱/线/饼/表格切换与三个跟问；事件回放去重，来源被替换后即使图表结果稍后完成也不重新入图。
- 严格校验显式选列、重复跟问、错误结果、双表歧义、1000行/100列上限；排除编号、证件号和 camelCase ID 列。
- 负数或全零占比默认回退表格，同时保留切换为柱状/折线的列；保留数值字符串、空值及无法安全绘制的原始单元格，阻止超出安全边界的小数被舍入后误作安全值。
- 新增会话来源与浏览器事件投影回归测试，更新构建和安装说明。

## 0.6.0

- DataHub 问表图表入口，ECharts 卡片、图型/表格切换和跟问建议。
