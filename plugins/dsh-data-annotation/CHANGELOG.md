# 更新记录

## 0.1.0-local.9

- AI 标注改为后端任务接口，支持创建、查询、显式取消和页面恢复观察；离页与 HTTP 断开不取消后台任务。
- 与数据源插件共享可选本机 HTTP 入口，Web 后端和 DSH 页面使用相同业务处理器、管理库与结果校验。
- 保留完整提交、会话绑定、版本及人工确认保护，提交成功不再等待消息受理确认；移除旧 /ai 长请求入口。
- 表标注提示词改为简短中文业务名称，示例覆盖养老、教育和企业；字段含义生成规则保持。
- 配套 dsh-sql 0.9.0-local.11，管理库保持 schema 6。

## 0.1.0-local.8

- 概览列表恢复“最近标注时间”列；标注状态旁新增已标注覆盖率进度条与百分比，未标注时显示“—”。
- 依赖配套 dsh-sql 0.9.0-local.10（提供 annotatedCount / requiredCount 统计）。

## 0.1.0-local.7

- 表格列宽重新分配，中文标注列为主；每页 20 行，提高宽屏空间利用率。
- 表/字段标注提示词改为自然描述文风，避免“可查”类模板化措辞，字数上限不变。

## 0.1.0-local.6

- 列表精简：表名不再重复显示库名，字段类型并入名称；备注与标注单行省略，完整内容悬浮可见；最近标注时间并入状态悬浮提示。
- 行内“确认/编辑”与概览“标注”改为小号有边框按钮，“确认”仅在可确认时显示。
- 表/字段标注提示词改为一句话概括并限制篇幅，避免罗列字段细节。

## 0.1.0-local.5

- 标注操作进度改为单行加载条：加载动画、状态文字与“取消操作”按钮，与数据源插件一致。
- 网络连接失败不再显示原始 `Failed to fetch`，改为中文提示“无法连接标注服务，请稍后重试。”

## 0.1.0-local.4

- 表/字段标注提示词明确本次选中数量与提交形态：每个选中对象一条，表标注仅提交 `tableId` 和 `text`，字段标注提交 `tableId`、`fieldName` 和 `text`；表任务说明 read 返回的字段仅供理解，不需逐字段提交。
- 提交数量或形态不符时返回期望数量、实际数量及具体原因，便于 AI 在同一会话内自行纠正。

## 0.1.0-local.3

- 修复 AI 表/字段读取结果中的 `undefined` 属性导致宿主拒绝工具输出；仅返回目录已提供的属性，缺省类型及备注使用空字符串。
- 为字段读取和表结构分页增加无损 JSON 往返断言。

## 0.1.0-local.2

- 修复标注接口缺少 `/api` 前缀导致页面无法读取服务响应；前后端统一经宿主 API 入口。
- 增加页面首次请求与后端路由连通回归测试。

## 0.1.0-local.1

- 新增独立数据标注入口、数据源总览、表标注和字段标注。
- 支持红黄绿确认状态、单项及批量编辑确认、字段启停、筛选选择和 AI 结构标注。
- 配套数据源插件 local.9 与管理库 v6；保留原始备注，目录变更取消对应确认。
- 导入导出仅占位；关系标注、最终确认流程和 Cube.js 查询接入留待后续。
