# 数据源插件更新记录

此插件独立于 DataHub 应用，仅涉及本仓插件及用户本机 DSH；不修改 DataHub 服务源码、业务数据库、受管提示词或部署。

## 0.7.0-local.3

- 保留问题、数据表、关联关系主标签，将问题页拆为「问题列表」「填写问题」子页，支持左右方向键及 Home / End 切换，移除顶部步骤导航。
- 填写页提供「整理问题」与「手动添加问题」两种入口；列表支持勾选、编辑、删除、搜索和筛选，手动新增以草稿加入，保存时由服务端分配正式 ID。
- 「确认并分析」先自动保存问题草稿，再使用返回的最新 revision 直接启动分析；保存失败或冲突停止启动并保留草稿，防止连续点击重复提交。移除预览确认及批次选择界面，后台仍默认每批 5 个问题串行执行。
- 最新任务以简短状态呈现，错误默认折叠，详细过程进入实际后台会话查看；保留取消与有效失败任务的重试，已完成批次不重跑。
- 仅当前问题快照对应的最新分析成功后自动进入数据表，未保存的表或关系草稿继续保留；问题整理及其重试不会触发分析结果导航，表范围与关系仍分别确认。
- 数据源列表名称列 260px、类型列 150px，操作列右对齐；新控件继续继承官方主题变量、悬停与焦点样式。
- 插件独立版本升级，DataHub 应用仍为 v0.33。数据库及服务器基础设施变更：无；保留 local.2 及更早版本历史和原有官方安装、回退流程。

## 0.7.0-local.2

- 修复深色主题白底浅字：移除官方不存在的 `bg-elevated`、`border-1` 等变量及固定浅色回退，使用真实背景层级、输入、边框和文字 token。
- 列表、表头、卡片、弹框、表单、主按钮、悬停/焦点、选中状态及状态提示统一跟随官方主题；默认主按钮采用官方黑白配色，主题包可覆写。清理固定蓝色和引擎字标的内联配色。
- 直接继承 Host 的主题变量和原生控件 color-scheme，主题切换不重挂载页面，保留输入草稿；没有额外的插件主题状态。
- 增加安装版官方亮暗变量夹具与桌面主题回归，覆盖初始暗色、动态切换、自定义变量覆写、主要正文和主按钮对比。
- 仅修改客户端样式与测试/说明；连接、密码、问题流程与后台桥接逻辑保持。数据库及服务器基础设施变更：无。

## 0.7.0-local.1

- 将最新 v0.10/v4 设计实现为实际插件：连接列表、默认 MySQL 的连接弹框、问题/数据表/关系三页和步骤导航。页面使用 React 本地状态切换，适配 Host 模块容器。
- 问题整理创建真实 DSH 后台会话，保存实际会话 ID 后发送，保留 requestId 并等待会话 flush。结构化工具回执持久化成功后才回填问题与分析结果，原问题优先去重，扩展问题默认不勾选。
- 分析前展示全部已选问题的完整快照；批次串行执行，失败暂停、失败批次重试、已成功批次不重跑。支持取消，重启中断须人工重试，拒绝旧会话、旧尝试、过期快照和取消后的晚到提交。
- 模型提议的表字段通过真实数据库结构核验；保留人工字段选择、说明和关系端点。表范围与关系分别确认，变更问题后清除确认，已选关系须显式复核当前来源。
- 流程单独持久保存于 `datasources/workflow.json`，串行原子写入和 revision 冲突检查防止覆盖；页面轮询保留未保存草稿。连接及密码继续使用已有存储，不迁移或重写用户凭据。
- 数据库表、字段、索引、约束、初始化及回填：无。DataHub 服务、端口、Nacos、容器、受管提示词及公共 Skill 变更：无。仅增加插件自己的本地流程状态文件及 Host 内部路由/工具注册。
- 后端、Host 契约、流程竞态及真实 SQLite 集成共 84 项回归通过。浏览器交互、归档与实际安装的核验记录随本地交付保留；测试替身不代表当前 GUI 已加载新版或真实模型分析通过。
- 安装和回退沿用正式 Desktop CLI。需要当前 Host 加载新工具与新客户端；只刷新页面不能保证 Host 代码更新。更新前安装包保留用于回退。

## 0.6.0-local.2

- 修复凭据记录协议：使用 DSH 原生支持的 `grant` 保存 `payload.password`，不再写入自定义 `database-password` 类型；读取校验记录类型和字符串密码。
- 密码保护以 DSH 模型密钥的现有机制为标准：原生 credentials 服务保存，Host 取用，页面及三个 SQL 工具不返回原文。保护依赖本机权限，不额外引入凭据服务、加密组件或 Agent 读取隔离。
- 补强原生协议测试替身，覆盖旧类型拒绝、持久化后新服务/运行时重载、编辑保留及删除后的重载，并断言公共响应不含密码。
- 提供仅修复本插件旧类型的 [修复脚本](./scripts/repair-native-credentials.mjs)，使用正式 DSH 解析器验证及原子写入，只修改类型；默认 dry-run，保留密码和其他凭据的值，不输出秘密。
- 36 项后端/Host 测试及语法检查通过；实际安装的 DSH 原生解析器合成回归通过。开发机旧记录修复后，已有 MySQL 连接测试与 `SELECT 1` 均成功，未读取业务数据。
- 安装与回退继续使用 Desktop 自带正式 CLI；安装更新后需完整退出再重开 DSH，加载修复后的 Host 代码。详见 [README](./README.md)。

## 0.6.0-local.1

- 基于上游 `dsh-sql@0.5.9` 新增独立数据源页面，入口位于插件与自动化任务之间。
- 支持 MySQL/PostgreSQL/SQLite 连接新增、测试、保存、编辑和删除。
- 仅注册 `sql_list`、`sql_query`、`sql_schema`，保持只读 SQL、真实行列、1000 行上限及保存后下次调用生效。
- 初版 34 项测试与桌面客户端夹具 36 项通过，但原生凭据测试替身未约束记录类型，未发现自定义类型在原生解析器重载时被拒绝；已在 local.2 修复并增加回归。
