# 数据源插件更新记录

此插件独立于 DataHub 应用，仅涉及本仓插件及用户本机 DSH；不修改 DataHub 服务源码、业务数据库、受管提示词或部署。

## 0.6.0-local.2

- 修复凭据记录协议：使用 DSH 原生支持的 `grant` 保存 `payload.password`，不再写入自定义 `database-password` 类型；读取校验记录类型和字符串密码。
- 密码保护以 DSH 模型密钥的现有机制为标准：原生 credentials 服务保存，Host 取用，页面及三个 SQL 工具不返回原文。保护依赖本机权限，不额外引入凭据服务、加密组件或 Agent 读取隔离。
- 补强原生协议测试替身，覆盖旧类型拒绝、持久化后新服务/运行时重载、编辑保留及删除后的重载，并断言公共响应不含密码。
- 提供仅修复本插件旧类型的 [修复脚本](./scripts/repair-native-credentials.mjs)，使用正式 DSH 解析器验证及原子写入，只修改类型；默认 dry-run，保留密码和其他凭据的值，不输出秘密。
- 36 项后端/Host 测试及语法检查通过；实际安装的 DSH 原生解析器合成回归通过。开发机旧记录修复后，已有 MySQL 连接测试与 `SELECT 1` 均成功，未读取业务数据。
- 安装与回退继续使用 Desktop 自带正式 CLI；安装更新后需完整退出再重开 DSH，加载修复后的 Host 代码。详见 [README](./README.md)。

## 0.6.0-local.1

- 基于上游 `dsh-sql@0.5.9` 新增独立数据源页面，入口位于插件与自动化任务之间。
- 支持 MySQL/PostgreSQL/SQLite 连接新增、测试、保存、编辑和删除。
- 仅注册 `sql_list`、`sql_query`、`sql_schema`，保持只读 SQL、真实行列、1000 行上限及保存后下次调用生效。
- 初版 34 项测试与桌面客户端夹具 36 项通过，但原生凭据测试替身未约束记录类型，未发现自定义类型在原生解析器重载时被拒绝；已在 local.2 修复并增加回归。
