# 会议检索与原话证据追溯

## 适用场景
当用户问「上周评审会怎么定下来的」「谁说过月底前上线」「找一下所有提到某客户回款的会议原话」时触发。

## 标准步骤
1. **先查结构化会议列表**：调用 `echomind_list_meetings` 按关键词、时间范围或状态筛选相关会议。
2. **读取结构化纪要**：对最相关的 1～3 场会议调用 `echomind_get_meeting` 获取结论、决定、议题与待办。
3. **按需定向追溯原话**：需要核对具体措辞或时间点时，调用 `echomind_search_transcript` 传入 `meetingId`（或留空跨会检索）、`keyword`、`speakerName`、`startMs` / `endMs`，仅取命中片段与上下文。
4. **据实作答**：引用原话时必须标明会议名称、发言人、时间点与证据编号（如 `seg-0018`），提醒用户可在会议详情面板点击对应片段直接定位播放原声；若未检索到证据，如实说明未找到，绝不臆测。
5. **可选图表呈现**：当用户需要统计多场会议分布或待办数量且宿主具备 `query_result_chart` 工具时，可直接使用 `echomind_list_meetings` 输出的表格行列绘图。
