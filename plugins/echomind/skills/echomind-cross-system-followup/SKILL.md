# 会议纪要跨系统联动跟进

## 适用场景
当用户说「对照上周客户会议纪要和履约无忧里的合同节点，看哪些回款有延期风险」或「把刚开完的客户拜访纪要整理成销售跟进要点」时触发。

## 标准步骤
1. **提取会议承诺**：调用 `echomind_list_meetings` 和 `echomind_get_meeting` 获取目标会议的结论、决定与待办；必要时用 `echomind_search_transcript` 核实金额、日期等关键原话细节。
2. **联动业务数据（按宿主已安装插件按需调用）**：
   - 若涉及合同付款节点或三流回款且宿主已安装履约无忧插件，结合 `contract_query` 核对合同履约现状；
   - 若涉及客户商机推进或拜访日报且宿主已安装销售管理插件，先核对现状再起草跟进要点；
   - 若需汇总对比多场会议数据且宿主已安装 `query_result_chart`，可调用图表工具呈现。
3. **清晰区分来源并交由用户确认**：输出对照表时明确区分「会议纪要承诺」与「业务系统记录」来源；如需在飞书建待办，必须通过 `echomind_stage_todo_push` 由用户在卡片确认推送。
