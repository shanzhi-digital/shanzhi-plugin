# 履约无忧

在 DeepSeek Harness 里直接问合同、回款和流水：识别合同 PDF 或扫描件并入库，查履约进度和待回款节点，对账银行流水和发票，看履约看板，并在右侧预览合同与票据原件。

插件以你在履约系统里的账号身份工作，能看到和能改的内容与你在履约系统网页里一样。

## 连接账户

第一次使用前，需要把 DeepSeek Harness 连接到你的履约系统账号。整个过程在浏览器里完成，不需要在 DeepSeek Harness 里输入账号密码。

1. 在插件页点「管理」，再点「连接账户」。也可以在「设置 → 履约无忧配置」里操作。
2. DeepSeek Harness 会弹出一个窗口，显示一串**校验码**，同时在浏览器里打开履约系统的授权页。浏览器没有自动打开时，点窗口里的「没有自动打开？点这里打开授权页」。
3. 在授权页登录履约系统（已登录就跳过），核对页面上的校验码和 DeepSeek Harness 里显示的一致，选好有效期（30、90 或 180 天），点「授权」。
4. 回到 DeepSeek Harness，窗口会显示「已连接：张三（zhangsan）」，就可以开始用了。

校验码 10 分钟内有效。只有在你刚刚点了「连接账户」时才在授权页点「授权」；看到不认识的授权请求，点「拒绝」。

## 试用

插件页右上角的「试用」会打开一个新会话，并在输入框里填好一句示例问题（不会自动发送），你可以改完再发。还没有连接账户时，会先带你完成授权，再打开会话。

插件页下方的「试试这样问」里有几个常用问法，点一下就会用这句话开始新会话：

- 本月有哪些待回款的节点？
- 查一下合同号 HT-2026-001 的履约进度
- 哪些流水还没匹配到合同？
- 我负责的合同里，哪些付款节点下个月到期？

也可以直接在对话里提问，或者把合同 PDF、扫描件拖进对话，让它识别并生成「合同识别核对卡」，核对无误后一键入库。

## 管理账户

插件页的「管理」（或「设置 → 履约无忧配置」）列出所有已连接的账户：

- **当前使用**：对话里的查询和录入都用这个账户。可以连接多个账户，在账户右侧的「⋯」菜单里点「设为当前」切换。
- **已过期 / 已失效**：授权到期，或者在履约系统里被吊销了。点「重新授权」，按上面的步骤再授权一次即可。
- **断开连接**：在「⋯」菜单里点「断开连接」并确认。插件会通知履约系统吊销这台设备的授权，并删除本机保存的令牌。
- **连接另一个账户**：再走一遍授权流程。在授权页登录哪个账号，就连接哪个账号；同一个账号再次授权会替换旧的授权。

插件页标题旁会显示连接状态：「已连接 · 张三」「授权已失效」或「未连接」。

对话中如果出现「还没有连接履约系统账户」「履约系统授权已过期」或「履约系统授权已失效」的卡片，点卡片上的「连接账户」完成授权，然后回复「继续」，刚才的问题会接着处理。

在履约系统网页里，也可以从用户菜单进入「插件授权」，查看并吊销用你的账号授权过的设备。

## 服务器与识别设置

在「管理」窗口展开「服务器与识别设置」：

- **服务器地址**：履约系统的接口地址，一般以 `/api/v1` 结尾。已连接账户时更换地址，会先提示确认，保存后断开全部账户，需要在新服务器上重新连接。
- **OCR 地址 / OCR Key**：识别扫描件和图片用的 DeepSeek OCR 服务。Key 只显示是否已设置和打码后的几位，可以替换或清除。没有设置时，会使用环境变量 `DEEPSEEK_API_KEY`。
- **测试连接**：用当前账户访问一次履约系统，确认地址和授权都正常。

## 令牌存在哪里

授权后，履约系统签发的访问令牌只保存在这台电脑上，界面上任何地方都不会显示它：

- 一般情况下保存在 DeepSeek Harness 的凭据存储中（`~/.dsh/.credentials.yaml`，仅本人可读）；
- 如果当前环境没有凭据存储，保存在 `~/.contract-sure/credentials.json`（仅本人可读）。

「管理」窗口底部会说明当前用的是哪一种。OCR Key 和令牌存在同一个地方。`~/.contract-sure/dsh-config.json` 只保存服务器地址、OCR 地址和账户的姓名、部门等公开信息。

## 从 0.1.0 升级

- 不再支持在插件里输入账号密码，也不再支持手动粘贴令牌，统一改为浏览器授权。
- 旧版本保存的令牌在新版履约系统上会失效。升级后请在「管理」里重新「连接账户」一次。
- 已设置的 OCR Key 会自动迁移，不用重新填写。
- 需要履约系统先升级到支持插件授权的版本（由系统管理员完成）。

## 支持的文件

- 识别合同：PDF（电子版直接读取文字，扫描件自动走 OCR）、PNG、JPG、TXT、Markdown；
- 上传原件与凭证：PDF、Word（docx）、Excel（xlsx、xls）、PNG、JPG；
- 导入银行流水或发票：Excel（xlsx、xls）；
- 单个文件不超过 20MB。

## 常见问题

**浏览器没有打开授权页？** 点授权窗口里的「没有自动打开？点这里打开授权页」。

**提示「授权请求已过期」？** 10 分钟内没有完成授权，点「重试」会生成新的校验码。

**提示「你在履约系统里拒绝了这次授权」？** 如果是误点，点「重试」重新授权。

**对话里提示授权已失效？** 授权到期或在履约系统里被吊销了，点卡片上的「连接账户」重新授权，再回复「继续」。

## 工具清单

| 工具 | 用途 |
| --- | --- |
| `contract_config` | 查看连接状态和当前账户（不能修改配置） |
| `contract_read_document` | 读取合同 PDF、图片或文本，扫描件自动走 OCR |
| `contract_stage_draft` | 校验识别结果，生成可编辑的「合同识别核对卡」 |
| `contract_confirm_save` | 确认创建合同并归档原件 |
| `contract_query` | 查询合同列表，或查看合同详情与原件清单 |
| `contract_dashboard` | 履约看板指标和 12 个月趋势 |
| `contract_manage_flow` | 导入流水、查未匹配流水、人工匹配、上传节点凭证、指定付款日期 |

列表和趋势数据可以配合「问数表格与图表」插件（`@local/datahub-echarts`）展示为交互表格和图表。
