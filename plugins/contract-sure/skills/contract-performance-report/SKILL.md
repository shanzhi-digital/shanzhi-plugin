# 履约月报

用 `contract_dashboard` 的数据写一份能直接给领导看的月度履约报告。

## 什么时候用

- 用户要月报、阶段性总结、给领导的履约汇报，或想知道「这个月整体怎么样」。
- 不适用：要具体的催款清单，用「回款节点跟进」skill（`contract-payment-followup`）；要逐份排查问题合同，用「合同风险排查」skill（`contract-risk-review`）。

## 开始前

- 需要已连接履约系统账户。任何工具返回 kind 为 `contract-sure-auth-required` 时：把 message 原样转告用户，停下等用户回复「继续」，不要重试或绕过。
- 确定**报告月份**：用户说了就用用户的；没说时，每月 1～5 号默认写上个月，其余日期默认写本月（截至今天），并在标题里写明。
- 确定**范围**：默认分别看销售合同和采购合同。用户只关心一类时只看那一类。

## 第 1 步：取数据

调用 `contract_dashboard`，分两次：

1. `contractType=1`（销售合同），`year` 填报告月份所在年份。
2. `contractType=2`（采购合同），同一年份。

报告月份是 1 月时，上月在去年：再用 `year` 填去年各调一次，只取 12 月那一行做对比。

**不要用不带 `contractType` 的那种调用写月报**：它会把销售回款和采购付款混在一起算成「收入」，支出也是 0，数字没法解读。

每次返回：

- `summary`：截至今天的累计指标（不是某个月的数）。
- `columns` + `rows`：1～12 月的月度趋势，列是「月份、签约金额（元）、收入金额（元）、支出金额（元）、逾期应收应付（元）」。

各指标怎么算、哪些是估算，见 `references/dashboard-metrics.md`。写报告前必须读一遍，尤其是这几点：

- 销售合同的「支出金额」和「毛利率」是按回款的 70% 估算的成本算出来的，**不是真实数据，报告里不要引用**。
- 月度「收入金额」按节点的应收日期归月，不是按实际到账日期。
- 金额单位都是元。报告里换算成万元，保留两位小数，并写明单位。

## 第 2 步：配图或表格

- 如果你的工具里有 `query_result_chart`（来自 @local/datahub-echarts 插件），对销售合同那次 `contract_dashboard` 调用画一张折线图：`sourceCallId` 填那次调用的 ID，`title` 写「YYYY 年销售合同月度签约与回款」，`dimension` 填「月份」，`measures` 填「签约金额（元）」「收入金额（元）」「逾期应收应付（元）」，`chartType` 填 `line`。需要时对采购合同那次也画一张（`measures` 用「签约金额（元）」「支出金额（元）」）。图表展示成功后，正文不再重复整张月度表。
- 没有 `query_result_chart`：在报告里放一张 Markdown 表，只列 1 月到报告月份，金额用万元。

## 第 3 步：找异常

对照 `references/dashboard-metrics.md` 里的「异常判断」逐条看，常见的有：

- 逾期率（`overdueRate`）偏高，或报告月的「逾期应收应付」比上月明显增加；
- 报告月回款比上月或前 3 个月平均值下降超过 30%；
- 签约多、回款少，回款明显跟不上；
- 未开票金额（`pendingInvoice`）占合同总额比例高，后续回款会被卡住；
- 草稿状态（`draftCount`）的合同多，说明录入后没有确认。

只写数据里真的看得出来的异常，每条附上具体数字。想知道是哪些合同拖累的，可以用 `contract_query`（`mode="list"`，`status=1`）取列表，按「逾期金额（元）」从大到小列前 5 份，写进异常说明。

## 第 4 步：写报告

用 `templates/monthly-report.md` 的结构写。要求：

- 第一段就给结论：一两句话说清这个月好还是不好、最大的问题是什么。
- 每个数字都能在工具返回里找到出处；算出来的（环比、占比）写明怎么算的。
- 建议要具体到动作，能落到人或合同的就点名，例如「请商务负责人张三本周跟进 HT-2026-018 的终验款 52 万元」。
- 截至今天的累计指标和某个月的月度数字分开写，不要混在一句里比较。

## 常见问题

| 现象 | 处理 |
|---|---|
| 某类合同的 `summary` 全是 0 | 说明这一类没有合同或不在你的查看范围内，报告里写「暂无数据」，不要编 |
| 月度趋势全年都是 0 | 可能是节点没有应收日期，或回款还没关联到节点（三流核对没做）。如实说明，建议先做三流核对 |
| 用户要季度报或年报 | 同样的方法，把月份范围换成季度或全年，标题和对比口径相应调整 |
